Concept. Without context, Claude answers Anthropic's internal business questions at 21%. Give it precision as infrastructure, a governed semantic layer and skills that route it to the right definitions, and the same model reaches 95%. Here the same three steps run across a company, not one analyst: precision supplies the definitions, execution runs the query, verification gates it. Every step runs as SQL. Intuition. One analyst runs the three steps by hand: precision, execution, verification. A company wires them into infrastructure so thousands of questions a week get the same treatment. The model still only generates; the steps stay yours.

Case Study 1.3 Reading Time: 5 mins

A stakeholder asks in Slack: "How many active users did we have last week?" Claude writes SQL, runs it, and returns a confident, wrong number, because "active user" has a dozen definitions in the warehouse and the model picked one. That is runs ≠ correct across a company. Anthropic's data team wrote up how they closed it in "How Anthropic enables self-service data analytics with Claude".

The 21% is the bare model: it can run and retry against the warehouse, so multi-shot execution is already there, but with no context it guesses what "active user" means. The definitions and the routing to them lift it to 95%. The third number says how: handing the model the company's entire history of past SQL, raw, moved accuracy less than a point. Structure does the work, not raw access.

These are Anthropic's internal numbers: their own warehouse, their own questions, scored on their own offline evals. They are one company's results. They are not BIRD, the general benchmark that spans many varied, complex external databases. On the public BIRD leaderboard, execution accuracy ranges widely (roughly 16 to 77 percent); 95% on your own warehouse is a different, narrower test, and the blog never runs on BIRD. The method is what carries over: context and checks lift a bare model, at one desk or across a company.

The Stack Is the Three Steps

The same three steps you ran by hand, now built as infrastructure, one person versus a company:

Step You, one query Anthropic, every query
Precision the spec in your prompt a governed semantic layer; skills route the model to the ~30 docs that matter
Execution run it in a CLI the agent loop, automated
Verification a debug table the same table as a regression suite of evals, gating each domain at ~90%

Both scales refuse the same wrong answer, the model's guess. The model writes the query; precision and verification stay yours.

Takeaway: The bare model scores 21% on Anthropic's own data; the three steps lift it to 95%. The numbers are Anthropic's internal evals, separate from the public BIRD leaderboard, but the method is the one you run by hand: precision, execution, verification, all on SQL.
